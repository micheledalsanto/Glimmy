# 🌟 Glimmy – Learn AI Through Play!

**Glimmy** is a playful educational platform designed to introduce children (ages 5–10) to the world of Artificial Intelligence through games, stories, and a friendly guide: **Glimmy**, the bouncing robot star.

---

## ✨ Features

- 🎮 **7 mini-games** to learn AI concepts — including **Train the Robot**, where kids teach a robot by example and see how AI learns from data
- 🏆 **Real progression system**: points, daily streaks, stats and 15 unlockable badges earned by actually playing
- 🤖 **Interactive mascot**: Glimmy reacts to wins and mistakes, celebrates with confetti and talks via speech bubbles
- 🔊 **Voice narration (TTS)** for stories, quiz questions and phrases — great for pre-readers
- 🎵 **Sound effects** generated with WebAudio (no assets, toggleable)
- 🌐 Multilingual: Italian, English & Spanish
- 📱 Mobile-friendly, responsive, premium "airy" design
- ♿ Respects `prefers-reduced-motion`

---

## 🛠️ Built With

- [Vue.js 3](https://vuejs.org/) + TypeScript
- [Vite](https://vitejs.dev/)
- [TailwindCSS 3](https://tailwindcss.com/)
- [Vue Router](https://router.vuejs.org/)
- [Vue I18n](https://vue-i18n.intlify.dev/)
- Web Speech API (text-to-speech) & WebAudio (sound effects)
